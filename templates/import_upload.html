Or bring in a class list and marks from Excel, Google Sheets (download as .xlsx or .csv) or another gradebook's export. You'll check how each column is read before anything is saved, and re-importing an updated sheet only changes what's different.

What works best

  • One row per student, with a header row on top.
  • Name columns (First / Last, or one "Name" column) and optionally a student number.
  • One column per assessment. Headers like Quiz 1 (/20) set the "out of"; 1.2 Lab puts it in Module 1.
  • Marks can be points, percentages or decimals. Cells with formulas use their calculated value.
  • Text such as "M", "missing", "X", "excused" or "late" is understood.
